# ultimate_game
GAME PROPOSAL

Game Title
Aurora Run (working title; you can change it)

Main Goal
Drive a car along a mountain road under the northern lights, dodging traffic and obstacles for as long as possible while earning a high score from near misses.

Player Controls

Left / Right arrow keys: steer between lanes
Up arrow: speed up
Down arrow: slow down
Enter or Space: start or restart
Best played on a laptop or desktop with a keyboard (phone controls are not part of version 1)

Gameplay
The car stays near the bottom of the screen while the road scrolls toward the player. Other cars and obstacles (such as rocks) appear in the lanes and the player has to steer around them. The background shows an aurora sky and large mountains along the sides of the road. Traffic gets faster and more frequent over time, so the game gradually gets harder. The game runs entirely in the browser as a static site.

Scoring

The player earns points for near misses: passing close beside another car without touching it.
A near miss also refills some fuel.
The highest score of the session is shown on screen.

Win/Lose Rules

This is an endless game, so there is no final win. The goal is to beat your own high score.
The player starts with 3 lives and loses one life each time the car crashes into traffic.
Fuel drains steadily. The player can also lose by running out of fuel.
The game is over when all 3 lives are gone or the fuel reaches zero. A “Game Over” screen shows the score and a restart option.

First Version
Keep version 1 small so it can be finished and tested:

One road with 3 lanes and a simple colored car (shapes are fine, no artwork needed)
Steering, speed up and slow down
Falling traffic cars in random lanes
Crash detection, 3 lives, and a fuel bar
Near-miss scoring and a score display
Start screen and Game Over screen with restart
Simple background: a gradient aurora sky and basic mountain shapes (we only add animation later if time allows)

Later ideas (not in version 1): sound effects, a saved high score, phone touch controls, more obstacle types, and a moving aurora.

One assumption to check: I pictured a view looking straight down the road, with mountains on both sides, because it is easier to build and test than a true 3D look. If you imagined a different camera angle, tell me and I’ll adjust the proposal before you show your teacher.
